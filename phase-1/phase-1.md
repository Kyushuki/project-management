# Фаза 1: Выбор концепции проекта

**Задача** Придумать не менее 4 концепций программного проекта    


## Концепции

| Номер | Концепция                                                                                |
| ----- | ---------------------------------------------------------------------------------------- |
| 1     | Простое приложение для ручного/автоматического учета ежедневных расходов и доходов       |
| 2     | Мобильное приложение с геймификацией для обучения финансовой грамотности и контролю трат |
| 3     | ИИ ассистент по финансам                                                                 |
| 4     | Облачный сервис для совместного ведения конспектов и проектов студентами группы          |
| 5     | Приложение для практики речи на иностранном языке с ИИ учителем                          |
## Критерии

1. Критерий: Частота использования приложения пользователем \\ Степень автоматизации приложения \\ Время в приложении
    2. Критерий: Степень взаимодействия с другими пользователями
    3. Критерий: Влияние приложения на жизнь человека
    4. Критерий: Самостоятельность приложения в ОС (степень взаимодействия с компонентами ОС)

| Номер | Критерий                                           |
| ----- | -------------------------------------------------- |
| 1     | Востребованность продукта (спрос) на рынке         |
| 2     | Трудоемкость разработки (ресурсы, исполнители)     |
| 3     | Инновационность                                    |
| 4     | Зависимость от стороннего технического обеспечения |
