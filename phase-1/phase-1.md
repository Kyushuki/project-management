Фаза 1: Выбор концепции проекта
    Придумать не менее 4 концепций программного проекта:
    1. Простое приложение для ручного/автоматического учета ежедневных расходов и доходов.
    2. Мобильное приложение с геймификацией для обучения финансовой грамотности и контроля трат.
    3. ИИ ассистент по финансам.
    4. Облачный сервис для совместного ведения конспектов и проектов студентами группы.
    5. Приложение для практики устной/письменной речи на иностранном языке с ИИ учителем.
