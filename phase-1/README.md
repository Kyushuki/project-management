# Фаза 1: Выбор концепции проекта

Необходимо придумать не менее 4 концепций программного продукта и выбрать наилучшую из них для дальнейшей работы.
Выбор производится на основе коллективных методов таких как:
- нечеткий TOPSIS (Technique for Order of Preference by Similarity to Ideal Solution)
- четкий МАИ (метод анализа иерархий)

## Концепции

| Номер | Концепция                                                                                |
| ----- | ---------------------------------------------------------------------------------------- |
| А1    | Простое приложение для ручного/автоматического учета ежедневных расходов и доходов       |
| А2    | Мобильное приложение с геймификацией для обучения финансовой грамотности и контролю трат |
| А3    | ИИ ассистент по финансам                                                                 |
| А4    | Облачный сервис для совместного ведения конспектов и проектов студентами группы          |
| А5    | Приложение для практики речи на иностранном языке с ИИ учителем                          |

## Критерии

| Номер | Критерий                                           | Тип     |
| ----- | -------------------------------------------------- | ------- |
| C1    | Востребованность продукта (спрос) на рынке         | Выгода  |
| C2    | Трудоемкость разработки (ресурсы, исполнители)     | Затраты |
| C3    | Возможность монетизации                            | Выгода  |
| C4    | Зависимость от стороннего технического обеспечения | Затраты |
## Оценки
Для оценивания концепций по критериям используется трехточечная оценка.
Оценка эксперта альтернативы по конкретному критерию представляет собой набор трех чисел:
+ пессимистическая оценка
+ ожидаемая оценка
+ оптимистическая оценка
Оценки находятся в [таблице](https://docs.google.com/spreadsheets/d/185mWC6GHhVbfOfaIhyaJvHQ7jqEImJeZKMAULMTe8fQ/edit?gid=7884832#gid=7884832) 

В качестве значений используется ранжировка от 1 до 9, где:
+ 1 очень низкий(ая)
+ 5 средний(ая)
+ 9 очень высокий(ая)
и промежуточные значения между ними.
