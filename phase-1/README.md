# Фаза 1: Выбор концепции проекта

**Задача** Придумать не менее 4 концепций программного проекта    


## Концепции

| Номер | Концепция                                                                                |
| ----- | ---------------------------------------------------------------------------------------- |
| K1    | Простое приложение для ручного/автоматического учета ежедневных расходов и доходов       |
| K2    | Мобильное приложение с геймификацией для обучения финансовой грамотности и контролю трат |
| K3    | ИИ ассистент по финансам                                                                 |
| K4    | Облачный сервис для совместного ведения конспектов и проектов студентами группы          |
| K5    | Приложение для практики речи на иностранном языке с ИИ учителем                          |

## Критерии

| Номер | Критерий                                           |
| ----- | -------------------------------------------------- |
| C1    | Востребованность продукта (спрос) на рынке         |
| C2    | Трудоемкость разработки (ресурсы, исполнители)     |
| C3    | Возможность монетизации                            |
| C4    | Зависимость от стороннего технического обеспечения |
