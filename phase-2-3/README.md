### Постановка задачи
- **Цель** распределить 6 задач между 3-мя экспертами
- Каждая задача должна быть выполнена одним экспертом
- Нельзя дробить или назначать одну задачу двоим

$$
x_{ij}=\begin{cases}
0,\ если\ задача\ не\ назначена  \\
1.\ если\ задача\ назначена
\end{cases}
$$  где $i$ - эксперт, $j$ - задача.

Для распределения задач между экспертами максимизируем суммарную "полезность" 
$$
u_{ij} = желание_{ij} - \alpha * сложность_{ij}
$$
$\alpha$ - коэффициент, определяющий значимость сложности по сравнению с желанием. Было решено поставить его $=0.5$, считаем желание решения задачи более значимым, чем сложность.
Итого целевая функция выглядит так:
$$
max\sum\limits_{i=1}^{3}\sum\limits_{j=1}^{6}u_{ij}x_{ij}
$$
Ограничения исходят из постановки задачи:
- каждая задача ровно одному эксперту
- одному эксперту можно назначить не более двух задач
